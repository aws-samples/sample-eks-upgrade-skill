# sync-divergences.txt — known-intentional divergences between the two skill copies.
#
# One EXTENDED REGEX (ERE) per line. misc/sync-copies.sh treats any line that
# differs between the parent copy and the DevOps Agent port as EXPECTED (not
# drift) if the line matches ANY pattern here. Blank lines and #-comments are
# ignored.
#
# ANCHORING CONVENTION (read before adding a pattern)
# ---------------------------------------------------
# A pattern must be ANCHORED so it cannot excuse an arbitrary one-copy content
# edit that merely happens to contain a common word. Use one of:
#   * a path/filename/API token that only appears on divergence lines
#     (e.g. `(steering|references)/<file>.md`, `md_to_html\.py`,
#      `DescribeAddonVersions`), OR
#   * a `^`-anchor plus optional leading Markdown markup for tokens that begin
#     their line (e.g. `^Write to the workspace root`), OR
#   * a DISTINCTIVE MULTI-WORD CLAUSE unique to the intentional line — never a
#     bare 2-word English fragment like "chat response" or "script execution".
# A short unanchored token is a bug: it lets a genuine one-copy fix slip through
# as "expected". If in doubt, match more of the line, not less.
#
# The patterns capture the THREE documented axes of intentional divergence:
#   1. Directory names   — steering/ (parent) vs references/ (port)
#   2. Tool vs no-tool    — parent has tools/md_to_html.py + HTML output;
#                           the port renders inline and runs no scripts
#   3. Framing / vocab    — Claude Code file output vs DevOps Agent inline chat;
#                           CLI form (describe-addon-versions) vs API form
#                           (DescribeAddonVersions)
#
# Add a pattern here ONLY when you have confirmed a divergence is intentional AND
# anchored per the convention above. If a real content fix landed in one copy,
# mirror it into the other instead of whitelisting it.

# --- Axis 1: directory-name divergence (path form and prose form) ---

# prose that merely contains the word "steering" or "references".
